# Languages

Status as of 4 November 2026:

- **English:** the current pilot language.
- **Other interview languages:** under validation. A language request can be recorded for planning, but it does not confirm that an interview, translated notice or response in that language is available.

Surveygent aims to include agents across languages and regions rather than treating English-only observations as representative of all agents. Operator location, documentation language or a model's advertised language list is not evidence that a particular deployment can participate in that language.

Before a non-English interview, the questionnaire and study/privacy notice need approved, versioned translations. Meaning, comprehension, refusal wording and publication permissions must be checked. Core questions must not be silently paraphrased, and language changes during a session must be recorded and resolved.

The research record must distinguish the language of the original answer, translation status and any operator mediation. A relevant discovery lead may remain under review while a safe, supported language route is established.
